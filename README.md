# DPIP-Lego-Spawn
Generate a lego setup for DPIP data collection

Instructions:
- Q,W,E will change the perspective
- SPACE will generate a 3x3x3 Lego structure for the first part of the task. 
-- It will also take screenshots from each perspective and save the coordinates in a CSV, in "Lego Spawn\DPIP Lego Spawn_Data\Screenshots\" Named by date and time (MM-dd-yyyy_HH-mm-ss) 
- Left-Shift will generate a more complex structure for the second part of the task. 
-- It will also take screenshots from each perspective and save the coordinates in a CSV, in "Lego Spawn\DPIP Lego Spawn_Data\Screenshots\" Named by date and time (MM-dd-yyyy_HH-mm-ss) 
- X will delete all of the blocks
- 1, 2, and 3 will delete blocks from the corresponding levels

Using Unity Editor version 2022.3.44f1 and Blender 4.1
